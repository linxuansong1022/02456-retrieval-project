Use these interface rules

  • The encoder receives token IDs and an attention mask.
  • The encoder returns one vector for each input text: [batch_size, embedding_dim].
  • Each retrieval method receives question texts and a value for k.
  • Each retrieval method returns document IDs and scores for each question.
  • Sort results from the highest score to the lowest score.
  • Person C saves both encoders and the tokenizer settings. Person D uses these files for retrieval.

Connect the parts in three steps

  1. Check each part. Use the shared sample data and artificial inputs.
  2. Run a small experiment. Connect the encoder, training code, vector index, and evaluation code.
  3. Run the final experiments. Use the same evaluation settings for all methods.

Give each file one owner. Use separate Git branches. Each person writes the report section for that person's work.

All four people review the final results and explain the complete retrieval process.
